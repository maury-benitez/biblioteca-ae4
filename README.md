## Descripción

Sistema de gestión de una biblioteca que permite administrar libros, socios, categorías y préstamos, con generación de informes. Está desarrollado aplicando el paradigma orientado a objetos: abstracción, encapsulamiento, herencia, polimorfismo e interfaces.

## Sub-sistemas

| Código | Sub-sistema | Funcionalidades |
|---|---|---|
| RF1 | Logueo | Inicio de sesión, registración y recuperación de contraseña y de usuario |
| RF2 | Libros | Alta, baja, modificación y consulta de libros, con informes |
| RF3 | Socios | Alta, baja, modificación y consulta de socios |
| RF4 | Préstamos y devoluciones | Registro de préstamos y devoluciones, control de disponibilidad |
| RF5 | Categorías | Alta, modificación, baja y listado de categorías |

La especificación completa de requerimientos se encuentra en la carpeta `docs/`.

## Tecnologías

- Java (JDK 17)
- NetBeans (proyectos Ant)
- Git y GitHub para el control de versiones
